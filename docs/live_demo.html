What you'll be able to do

Learning Goals

By the end of this walkthrough, you should be able to:

  • Explain what JABS does, and why starting from a well-defined behavior (like grooming) makes a classifier's job easier
  • Read a JABS pose-estimation file and distinguish a keypoint's position from its confidence
  • Judge whether a session's pose quality is trustworthy enough to use - and recognize what bad pose looks like
  • Describe the JABS workflow end to end: pose → features → XGBoost classifier → behavior labels
  • Train a classifier and run it on new sessions, and explain what part of that is reproducible
  • Interpret classifier performance against ground truth, and explain why accuracy alone can mislead
