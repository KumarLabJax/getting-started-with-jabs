Annotation and Classification with JABS

Estimated time to read: 10-15 minutes Depends on: Precomputed Tracking & QC Unlocks: Results and Analysis

Everything so far has been about the data: loading pose, understanding confidence, filtering to trustworthy sessions. This page is the bridge to the part where you actually use JABS - the desktop app that turns your labels into a behavior classifier. It explains the loop conceptually and gets JABS installed and open; the hands-on labeling itself happens on the JABS Demo page.

Learning Goals¶

By the end of this page, you should be able to:

  • Explain the label -> train -> predict -> refine active-learning loop JABS uses
  • Install JABS and open a project from the command line
  • Know where the actual hands-on GUI work happens and what to expect there

The Active-Learning Loop¶

Label, train, predict, refine. You do not label an entire video up front. You label a modest number of example frames for your behavior, train a classifier on them, then use the classifier's own predictions to find where it disagrees with you - that disagreement is exactly where labeling next teaches the classifier the most. Each pass through the loop needs less new labeling than the last.

Concretely, inside a JABS project:

  1. Label - watch a video in the JABS window, mark frames as your behavior or not
  2. Train - JABS fits a classifier (this course uses XGBoost; JABS also supports Random Forest, its default, and CatBoost - see JABS documentation, User Guide: Classifier Types) on kinematic features computed from the pose keypoints over your labeled frames
  3. Predict - run the trained classifier on the rest of the video (or other videos in the project)
  4. Refine - compare the classifier's predictions against your own labels, find the frames where they disagree, label there next, and retrain

That loop is why JABS calls itself an active-learning system: the classifier tells you where it is uncertain, and that is where your next labeling effort goes furthest.

Installing JABS¶

Full installation instructions are maintained in the official JABS documentation, not duplicated here - they will stay current as JABS evolves:

  • JABS tutorial - installation, GUI walkthrough, CLI reference
  • JABS-behavior-classifier - source, releases, issue tracker

Version note. This course's material - the screenshots, menu layout, and default settings described here and on the Live Workflow page - was developed and tested against JABS 0.47.1 specifically (see this repo's requirements.txt). JABS is under active development; if a newer release looks or behaves differently from what is described here, check your installed version first (pip show jabs-behavior-classifier) before assuming something is broken.

If you are on the course VM, JABS 0.47.1 is already installed - there is nothing to do here.

Opening a Project¶

"A JABS project is a directory of video files and their corresponding pose estimation files."

  • JABS documentation, User Guide: Project Setup

Concretely, that's the same data/ layout used throughout this course's QC and ingestion pages

  • videos, pose files, and any existing annotations in one folder. The first time JABS opens a project directory, it creates a jabs/ subdirectory to hold project state: settings and metadata (project.json), your labels, generated features, trained classifiers, and the latest predictions.

Launch JABS pointed at that folder from the command line:

jabs /path/to/your/project

JABS opens with the project's videos listed in a sidebar. Select one to start reviewing frames and labeling. The JABS Demo page picks up from exactly this point, using the QC-passed sessions from the previous page as the project.

Where the Hands-On Work Happens¶

This page is conceptual - it does not run any code. The actual labeling, training, and classifying happens in two places:

  • JABS Demo - the notebook you actually run, either live in person on a course VM or async on your own machine. It hands off to the JABS GUI for labeling, then calls jabs-classify from the notebook to train and run the classifier on new sessions.
  • The JABS GUI walkthrough - a region-by-region preview of the JABS window, so you know what each panel does before you sit down and label for real.

Understanding Checkpoint¶

  1. In your own words: why does JABS ask you to label a few frames, retrain, and repeat, rather than asking for all your labels up front?
  2. What does the "predict" step in the loop actually give you that you did not already have after "train"?
