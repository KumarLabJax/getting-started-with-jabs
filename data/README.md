# data/

This directory holds behavioral data for the Kumar Lab JAX Short Course module.

## What is committed to this repo

| Path | Contents | Size |
|------|----------|------|
| `data/toy/` | Short video clips and matching pose HDF5 slices for environment verification and CI | Small — committed directly |
| `data/dense_gt_a1/` | Dense, hand-reviewed ground-truth session (see below) | ~4MB — committed directly |
| `data/dense_gt_a2/` | Second annotation pass of the same session, as its own project (see below) | ~4MB — committed directly |
| `data/pretrained/` | Fallback grooming classifier and its training report, trained in the JABS GUI on `data/zenodo_no_gt_cached/` | ~0.5MB — committed directly |

## What is downloaded at runtime

| Path | Contents | How to get it |
|------|----------|--------------|
| `data/dataverse/` | Full Kumar Lab dataset from Harvard Dataverse (`doi:10.7910/DVN/SAPNJG`) | `python student_scripts/download_dataverse.py` |
| `data/jabs_project/` | JABS project directory initialized from tracking files | `python student_scripts/prepare_jabs_project.py` |
| `data/predictions/` | JABS classifier output, per session | Generated by `jabs-classify` on the Live Workflow page |
| `data/zenodo/` | JABS Behavior Classifier Example Projects (grooming, single-mouse-behaviors) from Zenodo (`doi:10.5281/zenodo.16697331`) | `python student_scripts/download_zenodo.py --extract` |
| `data/zenodo_no_gt_cached/` | The grooming download without the held-out session 2010, with features cached by `jabs-init` (the training pool) | `python student_scripts/prepare_training_set.py` |
| `data/zenodo_scrubbed/` | The practice set students label in the GUI (see below) | `python student_scripts/prepare_course_data.py` (the launchers run it) |

The directories above are in `.gitignore` and will not be committed. Re-run the
download scripts after a fresh clone.

## Dense ground-truth holdout (`data/dense_gt_a1/`)

Session **2010** (grooming project) was removed from the `data/zenodo/jabs_grooming/` download and its `jabs/project.json` video manifest, and moved to `data/dense_gt_a1/` (`2010_pose_est_v6.h5`, `2010.avi`, plus its pre-computed classifier predictions under `predictions/grooming/`). `data/dense_gt_a1/` is a complete JABS project: its labels live in `jabs/annotations/2010.json` and its settings in `jabs/project.json`, so you can open the folder in the JABS GUI and see the labels, or pass it to `jabs-cli evaluate`. (Files JABS generates there, such as features, cache and classifiers, are gitignored.) It is fully annotated (~99% frame coverage) and is held out **entirely** from classifier training - it is used only as the dense, unbiased test set for evaluating classifier metrics (accuracy/precision/recall/F1) against real predictions. It is not regenerated by any download script, so unlike the directories above, **`data/dense_gt_a1/` is committed** rather than gitignored - re-create it by repeating the same move if `data/zenodo/` is re-downloaded from scratch and this directory is ever lost.

## Training pool and fallback classifier

`student_scripts/prepare_training_set.py` copies the Zenodo grooming download to `data/zenodo_no_gt_cached/`, leaves session 2010 out, sets the project up for the course (window size 60, balanced labels, cross-validation grouped by video) and caches every video's features the way the JABS GUI asks for them, so Train and Classify do not recompute them. The classifier in `data/pretrained/` was trained in the GUI on this pool; `developer/scripts/make_pretrained_classifier.py` documents how to rebuild it.

## Practice set (`data/zenodo_scrubbed/`): a subset of the Zenodo videos

The practice set students open in the JABS GUI is **not** the full Zenodo set. The deposit has 25 grooming videos; `student_scripts/make_scrubbed_practice_set.py` keeps the **10 shortest** (by frame count, ties broken by session id), so a complete pass - computing features, training, and classifying every session - fits in a live session. Classifying all 25 videos takes about 8 minutes on a laptop; the 10 shortest are about 10,000 frames in total.

- **Kept (10):** 2008, 2015, 3984, 2021, 2014, 2009, 2004, 2022, 2018, 4133.
- **Held out of the practice set (1):** 2010, the dense ground-truth session (`data/dense_gt_a1/`), never trained on.
- **Removed (14):** 2012, 2005, 2019, 4083, 2002, 2020, 2001, 2003, 2017, 2013, 2006, 2011, 2016, 2007. They are still in the full download (`data/zenodo/jabs_grooming/`); the generated `data/zenodo_scrubbed/jabs_grooming/README.md` lists each with its frame count and video size.
- **Labels:** half of the 10 keep their original Zenodo labels and half are unlabelled for students to label, chosen deterministically (see `SPLIT_SALT` in the script).

Change `PRACTICE_SESSION_COUNT` in the script to use more videos.

## Two annotation passes of session 2010

For the inter-annotator agreement section, session 2010 has a second annotation pass (a second annotator at a second time point), stored in its own blind project, `data/dense_gt_a2/`, next to the first pass in `data/dense_gt_a1/`. This is conceptual practice, not best practice: best practice is more than one densely labeled video.
